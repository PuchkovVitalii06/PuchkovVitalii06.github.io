# Правила проекта

Личная страница-визитка Виталия Пучкова: делает сайты для людей с малым бизнесом.
Одна страница, шесть экранов по порядку — первый экран, обо мне, что я делаю,
примеры работ, заявка, контакты.

## Технологии

- Сайт, который видит посетитель (папка `public/`), — обычные HTML, CSS
  и немного JS без фреймворков и без сборки. `public/index.html` можно
  открыть двойным кликом, но заявки без сервера рядом работать не будут.
- За страницей стоит маленький сервер на Node (`server.js`) — раздаёт файлы
  из `public/` и принимает заявки на `/api/leads`. Здесь фреймворки и
  npm-зависимости уже нормальны — это не касается того, что видит браузер.
- Секреты (`DATABASE_URL`, `BOT_TOKEN`, `TELEGRAM_CHAT_ID`) — только
  в переменных окружения на Railway. В коде и тем более в `public/`
  их быть не может: файлы оттуда скачивает любой посетитель.
- Пути к файлам внутри `public/` всегда относительные (`styles.css`,
  `images/photo.jpg`). Абсолютных путей и путей с диском (`D:\...`) быть не должно.
- В корне лежат `index.html` и `robots.txt` — они **не** часть сайта. Репозиторий
  называется `PuchkovVitalii06.github.io`, поэтому GitHub Pages публикует его
  всегда и выключить это нельзя. Чтобы по старому адресу не висела сломанная
  копия, корневой `index.html` перенаправляет на Railway, а `robots.txt`
  запрещает индексацию. Сервер их не отдаёт: он раздаёт только `public/`.
  Настоящая главная страница — `public/index.html`.

## Цвета

Заданы переменными в `:root` в начале `styles.css`. Новые цвета не вводим —
берём из этого списка.

| Переменная | Значение | Для чего |
|---|---|---|
| `--bg` | `#0f172a` | тёмно-синий фон страницы |
| `--surface` | `#1e293b` | фон карточек, чуть светлее |
| `--text` | `#e2e8f0` | основной текст |
| `--muted` | `#94a3b8` | приглушённый текст, подписи |
| `--accent` | `#38bdf8` | кнопки и ссылки |
| `--accent-dark` | `#0ea5e9` | наведение на кнопку |
| `--success` | `#34d399` | заявка отправлена успешно |
| `--danger` | `#f87171` | ошибка в поле формы или сбой отправки |

Тема тёмная: светлый текст на тёмно-синем. Текст бледнее `--muted` не делаем —
на телефоне при ярком свете он не читается.

## Шрифт

Системный, без подключения внешних шрифтов — страница грузится мгновенно:

```css
font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
```

Размеры крупных заголовков задаём через `clamp()`, чтобы они сами
подстраивались под ширину экрана.

## Тексты

- Всё по-русски.
- К посетителю обращаемся на «ты».
- Коротко и по-человечески, без канцелярита и слов вроде «инновационный»,
  «динамично развивающийся».

## Телефон

Главное требование: на телефоне всё выглядит нормально.

- Стили пишем сначала под узкий экран, десктоп добавляем через
  `@media (min-width: 768px)`.
- Горизонтальной прокрутки быть не должно — проверяем на ширине 390px.
- Кнопки и ссылки не ниже 44px, чтобы попадать пальцем.
- Высоту экрана задаём через `100svh` (с запасным `100vh`), иначе на iPhone
  низ срезает адресная строка.

## Заявка

- Поля: имя, как связаться (телефон или Telegram — одно поле), что нужно
  (список услуг), комментарий (необязательно).
- Проверка полей — и в браузере (`public/app.js`), и заново на сервере
  (`server.js`). Браузеру не доверяем: запрос на `/api/leads` можно
  отправить и в обход формы.
- Если запись в базу не удалась — посетитель видит ошибку, заявка не
  считается принятой.
- Если в базу заявка записалась, а уведомление в Telegram не ушло —
  посетитель тоже видит ошибку (так решил Виталий), но с честным текстом:
  заявка уже сохранена, страшного ничего не случилось.

## Согласие на аналитику

- Google Analytics подключён с Google Consent Mode v2 (`public/index.html`,
  начало `<head>`): по умолчанию `analytics_storage` и остальные три
  параметра — «отказано». Счётчик не ставит cookie и не хранит ничего,
  что можно связать с посетителем, пока человек не нажал «Принять».
- Баннер (`#consent-banner` в разметке, `public/consent.js`) показывается
  только тем, кто ещё не выбирал. Выбор хранится в `localStorage`
  (`cookie_consent`), поэтому баннер не появляется повторно.
- Значения по умолчанию задаются раньше `gtag('config', ...)` — это
  обязательный порядок для Consent Mode, менять местами нельзя.

## Проверка перед сдачей

Открыть страницу на ширине 390px и 1280px, убедиться, что нет горизонтальной
прокрутки и ничего не наезжает. В проекте есть скилл `check-landing`.
