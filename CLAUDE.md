# Правила проекта

Личная страница-визитка Виталия Пучкова: делает сайты для людей с малым бизнесом.
Одна страница, пять экранов по порядку — первый экран, обо мне, что я делаю,
примеры работ, контакты.

## Технологии

- Обычные HTML и CSS. Никаких фреймворков, сборщиков и npm-зависимостей.
- `index.html` открывается двойным кликом и работает без сервера.
- Пути к файлам всегда относительные (`styles.css`, `images/photo.jpg`).
  Абсолютных путей и путей с диском (`D:\...`) быть не должно.

## Цвета

Заданы переменными в `:root` в начале `styles.css`. Новые цвета не вводим —
берём из этого списка.

| Переменная | Значение | Для чего |
|---|---|---|
| `--bg` | `#0f172a` | тёмно-синий фон страницы |
| `--surface` | `#1e293b` | фон карточек, чуть светлее |
| `--text` | `#e2e8f0` | основной текст |
| `--muted` | `#94a3b8` | приглушённый текст, подписи |
| `--accent` | `#38bdf8` | кнопки и ссылки |
| `--accent-dark` | `#0ea5e9` | наведение на кнопку |

Тема тёмная: светлый текст на тёмно-синем. Текст бледнее `--muted` не делаем —
на телефоне при ярком свете он не читается.

## Шрифт

Системный, без подключения внешних шрифтов — страница грузится мгновенно:

```css
font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
```

Размеры крупных заголовков задаём через `clamp()`, чтобы они сами
подстраивались под ширину экрана.

## Тексты

- Всё по-русски.
- К посетителю обращаемся на «ты».
- Коротко и по-человечески, без канцелярита и слов вроде «инновационный»,
  «динамично развивающийся».

## Телефон

Главное требование: на телефоне всё выглядит нормально.

- Стили пишем сначала под узкий экран, десктоп добавляем через
  `@media (min-width: 768px)`.
- Горизонтальной прокрутки быть не должно — проверяем на ширине 390px.
- Кнопки и ссылки не ниже 44px, чтобы попадать пальцем.
- Высоту экрана задаём через `100svh` (с запасным `100vh`), иначе на iPhone
  низ срезает адресная строка.

## Проверка перед сдачей

Открыть страницу на ширине 390px и 1280px, убедиться, что нет горизонтальной
прокрутки и ничего не наезжает. В проекте есть скилл `check-landing`.
