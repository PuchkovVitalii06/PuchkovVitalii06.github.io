# Сайт-визитка Виталия Пучкова

Личный лендинг: кто я, чем занимаюсь, примеры задач, которые беру, и форма заявки. Сделан для тех, кто ищет разработчика сайта или лендинга для небольшого дела — мастера, маленького магазина, человека, который работает сам на себя — и хочет сразу понять, чем я могу помочь, и оставить заявку, не выходя за пределы одной страницы.

То, что видит посетитель — обычные HTML, CSS и немного JS без фреймворков и сборки. За страницей стоит небольшой сервер на Node: он отдаёт эти файлы, а заявки из формы сохраняет в базу PostgreSQL и сразу присылает мне уведомление в Telegram. Сайт собран в контейнер и работает на Railway, а короткий адрес на GitHub Pages ведёт на него.

Опубликованная версия: [puchkovvitalii06.github.io](https://puchkovvitalii06.github.io/)

## Что внутри сделано

- Форма заявки с проверкой полей — и в браузере, и заново на сервере — сохраняет обращение в базу и уведомляет меня в Telegram.
- Баннер согласия на аналитику (Google Consent Mode v2): пока посетитель не нажал «Принять», счётчик ничего не сохраняет.
- События в Google Analytics по кликам на кнопку, по контактам и по отправке заявки — видно, что на странице работает, а что нет.
- Вёрстка сначала под телефон: без горизонтальной прокрутки и с кнопками, по которым удобно попасть пальцем.
